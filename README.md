# Rupeexo

Trust-first financial intelligence platform built for disciplined retail investors.

## Overview

Rupeexo is a clean, no-hype financial analysis interface focused on:
- Fundamental screening
- AI-powered earnings summaries
- Portfolio intelligence
- Transparent, ad-free experience

## Current Tech Stack

Frontend:
- HTML
- CSS
- Vanilla JavaScript

Backend (Planned):
- Node.js
- PostgreSQL
